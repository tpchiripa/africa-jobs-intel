            About this data

            Observation, not forecast

            Every number on this page is a count of what employers actually wrote in real job postings — not a survey, not a model, not a prediction. Three distinct kinds of statement appear across this site:

            Observation
            "42.7% of collected Data Analyst postings mentioned SQL." A direct count.
            Interpretation
            "SQL appears strongly associated with Data Analyst hiring." A reasonable reading of the observation, not a fact on its own.
            Recommendation
            Anything suggesting what a person might do about it. This site currently makes none — it shows evidence, not advice.

            How a skill percentage is calculated

            For each role, a batch of real job postings is collected from public sources. Each posting's title and description are checked against a taxonomy of skill keywords (e.g. "Power BI", "PowerBI", "power-bi" all map to one skill). A skill's percentage is the share of postings in that batch whose text matched at least one keyword for that skill — reported as a fraction (e.g. "64/150") alongside the percentage, so the underlying sample is never hidden behind a single number.

            Sample size labels

            Small samples can be misleading, so every role carries a plain-language label based on how many postings back it:

            • Limited observations fewer than 20 postings
            • Emerging signal 20–49 postings
            • Moderate evidence 50–99 postings
            • Strong observed sample 100+ postings

            These are product-transparency labels, not formal statistical confidence intervals.

            Known limitations

            • This dataset represents observed job postings and should not be interpreted as a complete census of the South African labour market.
            • Some sources return only a text snippet of each posting rather than the full description, which can under-count skills mentioned later in a full listing.
            • A skill's absence from a posting's text doesn't mean the role doesn't need it — only that this specific wording wasn't present.
            • Data has been collected at a single point in time per role so far — there isn't yet a history to show genuine week-over-week or month-over-month trends.
